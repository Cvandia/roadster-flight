# ROADSTER / 飞跃发布会

适配手机的 WebGL 3D 喷气飞行游戏。银灰色 Roadster 外观按用户提供的 2026 发布会参考图片程序化近似重建，并非官方 CAD 资产。

## 运行

在此目录运行 `python -m http.server 8765 --directory dist`，浏览器访问 http://localhost:8765 。ES 模块需通过 HTTP 服务加载，不应直接双击 HTML。

## 操作

- 输入驾驶员名称，开启挑战；自动加速并通过 U 形陡壁跳台起飞。
- 手机长按压头 / 抬头，左翻 / 右翻，同时按住喷气按钮；支持多点触控。
- 电脑 ↑ / W 抬头、↓ / S 压头、← / A 左翻、→ / D 右翻、空格喷气，P 暂停。
- 每局 100% 固定燃料，总喷气时长 6 秒。车尾前推与车底辅助升力均随车身方向变化。
- 可连续侧翻、空翻，姿态通过四元数计算，推力在三维空间作用。首次触地按起点与落地点的地面直线距离 `sqrt(x²+z²)` 计分；名称、成绩和时间保存在当前浏览器中，最多保留最近 100 局。

无全球榜单或跨设备同步。视觉参考和开源许可证见游戏内致谢页面。
