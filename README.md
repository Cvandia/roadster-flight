# ROADSTER · 飞跃挑战

适配手机的全屏 WebGL 游戏，使用摇杆调节俯仰、翻滚与喷气。U 形跳台、固定 6 秒满推力燃料，以及起点至落点的地面直线距离计分。落地车轮须朝向着陆面，车身倾角不超过 25°；滑行速度超过 2 m/s 时，车头与行进方向偏差须不超过 60°。倒扣、侧翻、倒车或严重横滑落地不计成绩。前端与服务器使用同一判定，旧榜数据保留但不混入新规则榜。

- 手机支持两个摇杆同时拖动；左杆控制姿态，右杆上推喷气。
- 鼠标操作时，右杆释放后保持设定推力，回拉至中心关闭推力。
- 电机、风噪、喷气音效由 Web Audio 实时合成，首次用户操作后启用。
- 全球排行榜使用 Cloudflare D1；服务器重放固定步长物理模拟，计算实际成绩。
- 高空摄像机使用渲染插值与随帧率调整的过渡，地面使用 mipmap 纹理防止网格闪烁。

## 在线试玩

- [GitHub Pages](https://cvandia.github.io/roadster-flight/)
- [游戏与全球排行榜服务](https://roadster-flight-cj.arcane-krill-2332.chatgpt.site/)

GitHub Pages 直接发布 `public/play/` 的完整游戏文件，模型、Three.js、音效及物理均从 Pages 同域加载，不再嵌入外部游戏页面，也不依赖外部 CDN。排行榜是独立的可选联网功能，通过允许该 Pages 来源的 CORS 接口访问现有 Worker / D1 服务。

排行榜服务被网络阻断时，仍可立即起飞和完整游戏；落地操控记录保存在本机，刷新后仍会保留，并在连接恢复后自动重试服务器核验和上传。缓存的全球榜会标注为缓存，不会把本机记录冒充全球排名。若需要全球榜在特定网络始终可同步，仍需将 API 部署到该网络可达的服务商或自定义域名。

## 开发

依赖安装、构建、发布遵循 Sites 插件工作流。主要文件：

- `public/play/`：游戏、共享物理、声音和 3D 模型。
- `app/api/`：开始飞行、服务器复算成绩与全球排行榜 API。
- `db/schema.ts`、`drizzle/`：云端数据库表结构与迁移。
- `app/page.tsx`：全屏游戏入口。

本地预览需应用 D1 本地迁移，见 Sites Vinext 模板文档。正式数据库由 Sites 在发布时创建并迁移，本地预览数据不会上传。

模型按用户提供的 2026 发布会图片程序化近似重建，并非官方 CAD 资产。致谢见 `/play/credits.html`。
